## Overview

WebChat is a fully responsive full-stack web application that allows users to create servers, set up channels, and engage in real-time conversations with other members. This platform provides features such as:

- **Server and Channel Management**: Create and manage servers, and organize channels for specific topics.
- **Role and Member Management**: Assign roles to members, and kick users out of servers when necessary.
- **Audio & Video Calls**: Communicate through audio and video calls for more personal conversations.
- **File Sharing**: Share files, including images and PDFs, directly in chat.

With a user-friendly interface and powerful real-time communication features, WebChat brings seamless and interactive chatting to your fingertips.

---

## Key Features

- **Server Creation**: Easily create and manage multiple servers with custom roles for members.
- **Channel Management**: Organize discussions into various channels, keeping conversations focused.
- **Real-Time Chat**: Enjoy seamless text chats with instant messaging for all members of the server.
- **Audio & Video Calls**: Call your friends or team members for face-to-face communication.
- **File Sharing**: Upload and send PDFs, images, and other documents to your contacts in chat.
- **User Permissions**: Control user roles and permissions such as kicking members or promoting users to different roles.

---

## Technologies Used

- **Frontend**: React, HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Media Handling**: WebRTC for video/audio calls
